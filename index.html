Commands: Open Terminal in Editor

Launch terminal presets in the editor area with custom icons.

OpenVSX Listing VS Code Marketplace

What it does

  • Opens a terminal in the editor area and runs a preset command immediately.
  • Customize presets (nickname, command, icon) and hide/show status bar buttons.
  • Ships with quick presets for Claude, Codex, and Gemini.
  • Includes a Quick Pick command for fast launching.

Where to find it

Open the activity bar (the vertical strip of icons on the far left edge of the window). It usually contains:

  • Explorer (files)
  • Search
  • Source Control
  • Run & Debug
  • Extensions

You will see a Commands icon there.

Commands

  • Commands: Edit Presets
  • Commands: Pick Preset

Preset settings

Presets live in settings.json under commands.presets.

{
  "commands.presets": [
    {
      "id": "claude",
      "nickname": "Claude",
      "command": "claude",
      "icon": "asset:claude",
      "enabled": true,
      "showInStatusBar": true
    }
  ]
}
